# Submission description

ProofStack turns a candidate's portfolio into a personalized coding assessment. Candidates upload JSON or a text PDF, review their skills, and solve project and DSA tasks across three levels. Featherless provides task personalization and guarded hints. Reference checks validate tasks before release; deterministic tests grade the code. The report connects claimed skills with measured evidence and replays saved solution changes. Built on the Apache-2.0 SignalLoop foundation, with a portfolio-first interface, evidence reporting, scoring safeguards and isolated WASI deployment added for this hackathon.
